# The Austin Wine Merchant website redesign

A static redesign concept for The Austin Wine Merchant. Open `index.html` in a browser to view it, or publish the repo with GitHub Pages.

- `index.html`: homepage
- `bordeaux.html`: Bordeaux page with a filterable wine list
- All other pages are holding pages until they are designed
- `assets/`: styles, script and images

Wine data on the Bordeaux page is a sample of the first 25 reds from the current site. Prices and availability should be confirmed before launch.
